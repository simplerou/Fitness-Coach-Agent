# 版本路线

## V1.0.0：本机可运行基础版

- 浏览器原生 Web 页面由 FastAPI 同源托管，不需要 Node 或 Docker。
- 安全筛查 → 状态录入 → 今日建议 / 基础计划 → 训练日志打通。
- 状态与日志暂存在后端内存；单用户本机演示。

## V1.1.0：本机数据库持久化

- 连接本机 PostgreSQL，密码通过 `.env` 配置。
- 每日状态和训练日志写入数据库，服务重启后可继续查看。
- 安全暂停和计划暂时仍是进程内状态；服务重启后重新筛查。
- 首次启动自动创建表；当前只适合单用户本机演示。

## 后续 V1.x：演示版完善

- 增加历史趋势与简单周回顾。
- 根据实际演示问题完善表单校验、错误提示和固定验收场景。

## V2：可持续试点版本

- 在确认隐私、授权、删除与安全审阅责任后，评估账号、访问控制、数据库迁移和部署能力。
- 评估经过审核的运动知识库与模型辅助能力。

## 后续阶段

- 依据试点反馈决定是否制作微信小程序。
- 仅在真实验证平台能力、用户授权和维护成本后评估健康数据同步。

遇到的问题和解决方案记录于项目父目录的 `问题与解决方案.md`。
