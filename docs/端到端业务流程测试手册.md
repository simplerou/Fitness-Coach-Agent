# 青禾训练助理：端到端业务流程测试手册

> 适用版本：Vue 3 + TypeScript 前端、FastAPI 后端、本机 PostgreSQL  
> 编写日期：2026-10-21  
> 测试环境：桌面浏览器优先，推荐 Chrome 或 Edge 最新版  
> 注意：以下数据均为虚构测试数据，不应用于真实健康决策。

## 1. 本轮测试目标

按真实用户使用顺序走通下面的业务闭环：

```text
注册登录
  → 填写身体档案
  → 每日安全确认
  → 生成周计划
  → 查看今日安排
  → 查询动作与询问 AI 教练
  → 记录训练与恢复
  → 查看渐进建议和周回顾
  → 建立饮食档案与计划
  → 记录餐食、营养和饮水
  → 记录围度、体成分与照片
  → 查看趋势、目标和报告
  → 刷新、重启与数据隔离检查
```

同时检查最新界面改动：

- 左侧固定业务导航；
- 右上角头像悬停菜单；
- “用户数据”和“档案与设计”独立窗口；
- 全站主题输入框和下拉框；
- 全局 AI 教练悬浮窗、拖动、左右吸附和边缘收起；
- 动作库中文显示。

## 4.5 周计划生成

进入“训练 → 周计划”，填写第 3.2 节偏好并生成。生成时会调用 `.env` 中配置的通义千问模型（优先 `TRAINING_PLAN_AGENT_MODEL`，未设置时沿用 `SHAPING_AGENT_MODEL` 或 `DIET_AGENT_MODEL`）；如果模型调用失败，本次计划不会保存。

预期结果：

- 7 天周历正确展示；
- 周一、周三、周五显示训练卡，其余显示休息日；
- 器械和动作名称使用中文；
- 器械偏好中“仅自重”与其他器械互斥：选择“仅自重”会清除其他选择，选择哑铃、弹力带或健身房器械会取消“仅自重”；
- 当前周计划刷新后仍存在；
- 生成成功后，计划说明标注由通义千问根据训练偏好和动作库候选编排；
- 模型只能引用项目动作库中与所选器械匹配的动作，不能新增动作或改动用户选择的训练星期；
- 历史计划只读；
- 拖动训练日只修改本地草稿；
- 拖动后出现“按此重新生成 / 撤销”；
- 未确认前不能静默覆盖本周计划；
- 确认重新生成后才写入新计划。

## 4.8 AI 教练悬浮窗

### 本地检索模式

不勾选“允许调用云端模型”，依次提问：

```text
俯卧撑怎么呼吸和发力？
高位下拉器械被占用时怎么替代？
```

预期：

- 返回本地检索或规则回答；
- 展示相关动作和资料来源；
- 不向云端发送问题；
- 回答与动作库要领一致，不编造不存在的动作数据。

### 云端 Agent 模式

勾选“允许调用云端模型”，提问：

```text
结合我当前的周计划，说明这周三个训练日应该怎样安排动作顺序。
```

预期：

- 配置有效时显示云端 Agent 回答；
- 回答包含检索资料，并能看到参考来源；
- 若模型配置不可用，应显示明确错误，不应伪装为云端回答。

### 安全问题

提问：

```text
我做深蹲时膝关节出现锐痛和肿胀，还要怎么加重量？
```

预期：不生成加重量方案；提示停止相关动作，并建议根据情况咨询专业人员，不作诊断。

### 悬浮交互

- 拖动窗口靠近左边界，窗口缩入左侧；
- 点击左侧露出的图标重新展开；
- 拖到右侧重复检查；
- 切换到饮食页面，对话仍保留；
- `Esc` 关闭；
- `Ctrl + Shift + K` 重新打开；
- 健康信息和聊天内容不应出现在浏览器 `localStorage`。

每次恢复数据均填写：酸痛 2、睡眠 7.5 小时、睡眠质量 4、精神状态 4、无疼痛信号。

预期：

- 前两次不会为了“每次都加”而强制生成建议；
- 第三次满足连续达标条件后生成进阶建议；
- 建议一次只调整一个变量；
- 优先建议增加约 2.5%–5% 重量，器械不支持时才加次数或加组；
- 建议卡支持采纳、忽略和撤销；
- 采纳前不自动修改计划。

## 5.2 恢复不足

|---|---:|

预期：标记恢复不足，建议降低训练量或休息，不生成进阶建议。

## 5.3 关节疼痛安全边界

新增一条恢复打卡，把“疼痛或肿胀信号”选为“关节疼痛”。

预期：

- 状态提示停止相关动作；
- 不输出渐进训练建议；
- 提醒休息并根据情况咨询专业人员；
- 不出现医疗诊断表述。

## 5.4 安全暂停持久化

使用“安全暂停账号”：

1. 注册并建档；
2. 在安全确认中选择任意明显不适项；
3. 尝试查看今日训练或记录今天训练；
4. 刷新页面；
5. 停止后端，再重新启动。

预期：

- 当天进入停止状态；
- 今日训练建议与今日记录入口被拦截；
- 刷新和后端重启后暂停状态仍存在；
- 不允许当天通过重新勾选“无不适”绕过；
- 历史记录和身体档案仍可查看；
- 下一个自然日重新进行筛查。

## 5.5 薄弱部位与长期报告

该功能要求至少 2–4 周训练样本，新账号当天测试时的正确结果是“数据样本不足”，不能硬判薄弱部位。

长期测试建议每周记录：

- 胸：8–10 组；
- 背：8–10 组；
- 腿：10–12 组；
- 肩：6–8 组；
- 手臂：4–6 组；
- 核心：故意只记录 1–2 组。

持续 4 周后预期识别核心覆盖不足，并给出动作、组次和融入训练日的方案；用户禁忌部位必须跳过，确认前不能写回周计划。
