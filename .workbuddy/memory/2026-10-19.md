## 前端现状摸底（Vue3+TS 迁移前的基线）

- 前端仍是 vanilla：`web/index.html`(432 行/48KB)、`web/app.js`(2227 行/128KB)、`web/styles.css`(293 行/59KB)
- 后端 FastAPI 同源托管：`WEB_ROOT = PROJECT_ROOT / "web"`，`GET /` 返回 `web/index.html`，`/static` 挂 web 目录
- 会话为签名 Cookie（同源 fetch 自动携带），接口全在 `/api/*`
- 六个页面：today / plan / profile / log / diet / review，靠 `showPage(name)` 切 `.page` 的 active class
- 状态是约 30 个模块级 `let` 全局变量；渲染全靠 `innerHTML` 字符串拼接 + `escapeHtml()`；
  事件用 `addEventListener` + `event.target.closest('[data-xxx]')` 委托；弹窗用原生 `<dialog>.showModal()`
- 通知是居中模态 `notify(message, kind)`，带焦点返回（`noticeReturnFocus`）

## 前端构建验证（npm install + npm run build）

- 环境要点：`registry.npmjs.org` 在本沙箱**不通**（直连 curl 20s 超时/极慢，代理 000 超时）；
  `registry.npmmirror.com` 走沙箱代理**通**（0.36s）。构建一律用：
  `D:/node.js/npm.cmd install --registry=https://registry.npmmirror.com --cache web/.npm-cache --no-audit --no-fund`
- npm 11.17.0 + node v24.19.0。npm 新版有 allow-scripts 门禁，`esbuild@0.28.2` 的 postinstall 未执行，
  但 vite build 仍正常（esbuild 用预编译二进制，未受影响）。
- 结果：`npm install` 97 包/25s；`npm run build`（vue-tsc --noEmit && vite build）**通过**，47 模块，907ms。
- 产物 `web/dist/`：index.html 0.48kB、CSS 57.27kB、index-*.js 94.96kB、6 个视图 chunk 各约 0.42kB。
- ⚠️ 视图 chunk 极小是因为 `src/views/*.vue` 全是 250~266 字节的占位骨架（"今日功能将在阶段 3 迁入"），
  业务逻辑尚未迁移，构建通过 ≠ 功能完整。`web/app.js` 仍保留为原 vanilla 实现。
